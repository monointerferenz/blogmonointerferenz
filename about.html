About

yoctoblog is a small, static blog. It is a folder of hand-written HTML files, a stylesheet, and a short build script. There is no database, no framework, and no JavaScript to speak of.

How it is put together

  • Posts are plain HTML files in posts/. A new one is made by copying posts/_template.html and editing it.
  • The index and tag pages are generated by build.mjs, a dependency-free Node script that reads each post's <meta> tags.
  • Tags nest with slashes: code/rust/async also files under #code and #code/rust.
  • The feed lives at feed.xml.
  • The type is IBM Plex — Serif for reading, Sans for headings, Mono for dates, tags, and code.

Syntax highlighting is done in the browser with Prism, and the tokens are coloured to match the rest of the page rather than dragging in a separate theme.

Colophon

Written in a text editor. Served as static files. The whole thing is smaller than most single web fonts.

You can subscribe by RSS, or just come back and read.
